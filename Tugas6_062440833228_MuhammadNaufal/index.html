Cara melihat hasil di Console

  1. Jalankan halaman ini dengan Live Server.
  2. Tekan F12 (atau klik kanan, pilih Inspect) untuk membuka Chrome DevTools.
  3. Klik tab Console.
  4. Kalau masih kosong, refresh halaman dengan Ctrl + R .
  5. Contoh | cariProdukById(produk, 5) | filterStokTersedia(produk) | hitungDiskon(produk)

Yang tampil di Console: data awal (tabel), sparepart yang stoknya tersedia (filter), hasil pencarian berdasarkan id (find), dan harga setelah diskon 10% (map). Untuk mencari id lain, ubah nilai idDicari di script.js, simpan, lalu lihat Console lagi.
